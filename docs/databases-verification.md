## First adapter limits

The runner accepts a constrained table/index/direct-data SQL grammar. Stored procedures, triggers, views, dynamic SQL, privileged/history/cross-schema SQL and unsupported quoting fail before execution. Inspection can display these objects without granting execution support. Scheduled events or incomplete visibility make coverage unverified.

The product rehearsal adapter proves structure on an empty fixture. Data-changing migrations remain blocked until a sanitized data-fixture verifier is supplied; the real-data runner tests do not grant production admission to such migrations. Destructive/conditional downs need current eligibility checks and applicable tested restore coverage.

External restore evidence includes an actual inspected restored sandbox and explicit operator attestation of backup availability, restored data, compatible applications and recovery limits.
